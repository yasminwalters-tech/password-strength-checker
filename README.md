# 🔐 Password Strength Checker

## About This Project

This is a beginner Python cybersecurity project that checks the strength of a password using basic security requirements.

## What It Checks

- Password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

## Skills Demonstrated

- Python
- Conditional statements
- Variables
- User input
- Basic cybersecurity concepts
- Password security

## Purpose

I created this project while learning Python and cybersecurity fundamentals as part of my IT Cybersecurity & AI studies.

## Disclaimer

This project is for educational purposes. Do not enter real passwords when testing the program.
